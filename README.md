# 標案監看系統

自動抓「政府電子採購網」上指定機關（交通部公路局、參山國家風景區管理處等）的招標公告，剔除無法承接的甲級大案，產生一個含**即時倒數計時**的儀表板網頁，並可 Email 通知新案。

## 為什麼抓政府電子採購網，而不是各機關官網？

依政府採購法，各機關的招標公告都必須刊登在政府電子採購網（web.pcc.gov.tw），所以抓這一個來源就等於同時涵蓋公路局、各養護工程分局、參山處……未來要加日月潭、阿里山等其他風管處，只要在 config.json 加一行機關名稱即可，不用為每個機關官網各寫一支爬蟲。

## 安裝（只需一次）

1. 安裝 Python 3.10 以上（python.org，安裝時勾選 Add to PATH）
2. 打開命令提示字元（cmd），安裝套件：

```
pip install requests beautifulsoup4 lxml
```

## 使用

```
cd 這個資料夾
python tender_watch.py          # 抓取 + 篩選 + 產生 dashboard.html
python tender_watch.py --demo   # 不連網，用假資料先看儀表板長什麼樣子
```

跑完後打開 `dashboard.html`（雙擊即可），會看到：

- 每個標案的機關、案號、預算、截止投標、開標時間
- **倒數計時每秒更新**：紅色＝3天內截止、黃色＝7天內、綠色＝時間充裕、灰色＝已截止
- 上方可依機關切換、篩「投標中」「3天內截止」、關鍵字搜尋

## 篩選設定（config.json）

| 設定 | 用途 |
|---|---|
| 目標機關關鍵字 | 要監看的機關，用「名稱包含」比對。「交通部公路局」會連各區養護工程分局一起抓到 |
| 預算金額上限 | 超過此金額的案子剔除。預設 9,000 萬（約乙等綜合營造承攬上限）。**請依貴公司實際等級與最新法規調整**，例如丙等可改 27,000,000 |
| 排除資格關鍵字 | 標案資格出現「甲等綜合營造」等字樣就剔除 |
| 標題必含/排除關鍵字 | 進一步只看特定類型，例如只看含「工程」的案子 |

## 每天自動執行（08:30 / 13:30 / 17:30 三次）

**Windows（最簡單）：** 對 `setup_schedule.bat` 按右鍵 →「以系統管理員身分執行」，會自動建立三個排程（08:30、13:30、17:30），每次執行的訊息記錄在 `run_log.txt`。想立刻測試：

```
schtasks /run /tn "標案監看-0830"
```

要移除排程：

```
schtasks /delete /tn "標案監看-0830" /f
schtasks /delete /tn "標案監看-1330" /f
schtasks /delete /tn "標案監看-1730" /f
```

**Mac/Linux：** `crontab -e` 加入一行（三個時間一起設定）：

```
30 8,13,17 * * * cd /path/to/tender-watch && python3 tender_watch.py >> run_log.txt 2>&1
```

## Email 通知（可選）

config.json 的 `email通知` 改 `"啟用": true`，填入 Gmail 帳號與「應用程式密碼」（Google 帳戶 → 安全性 → 應用程式密碼申請，不是登入密碼）。有新公告或 3 天內截止的案子才會寄信。

## 已知限制與維護

- 政府電子採購網**改版時**，`parse_list_html()` 和 `fetch_detail()` 的解析規則可能需要微調（程式內有註解標明）。如果某天突然抓到 0 筆，先手動開採購網確認查詢頁是否改版。
- 「預算金額」有些案子在公告階段不公開，篩選時抓不到金額的案子**不會被剔除**（寧可多看到也不要漏掉），儀表板會顯示「未公告」。
- 資格判斷是關鍵字比對，最終能否投標請以招標文件為準。
- 請保留程式內的抓取間隔（2 秒），避免對政府網站造成負擔。
- 資料來源為政府電子採購網，引用請註明出處；投標一律以採購網原始公告為準。

## 承攬限額備忘（篩選門檻參考）

營造業法對綜合營造業承攬造價有限額規定（甲等不限、乙等與丙等有上限，數字會隨法規修正調整）。config.json 預設用 9,000 萬當上限，這只是常見的乙等參考值——**請依貴公司登記等級查證最新限額後修改**。
